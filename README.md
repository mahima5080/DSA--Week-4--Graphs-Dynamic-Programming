## 📁 Repository Contents
1. `1_bfs_dfs.cpp`: Implementation of BFS and DFS graph search traversals using Adjacency List.
2. `2_dijkstra_algorithm.cpp`: Shortest path algorithm implementation using priority queues.
3. `3_fibonacci_memo_tab.cpp`: Comparison of Top-Down Memoization vs Bottom-Up Tabulation DP techniques.
4. `4_knapsack_01.cpp`: Dynamic programming solution for the 0/1 Knapsack Optimization Problem.
5. `city_path_finder.cpp`: **Mini Project** — Route planner computing shortest distances between cities using Dijkstra's algorithm.
